# Content sources, provenance and licensing

Religious content enters the app **only** through `npm run content:build`, which reads pinned files from
`content-sources/` (listed with SHA-256, licence and provenance in `content-sources/manifest.json`) and refuses
to build if anything differs. Nothing is typed by hand, generated by AI, paraphrased or normalised.

## Quran text — Tanzil Uthmani 1.0.2

- File: `content-sources/tanzil/quran-uthmani.xml` (copyright block intact).
- Obtained from the PyPI package `pyquran==1.0.1`, whose bundled md5 (`6aae945d…`) matches the file; the
  official tanzil.net host was not reachable from the build sandbox.
- Licence: CC BY 3.0, verbatim copies only, attribution + link to tanzil.net (shown on the Sources screen and in
  every copied/shared ayah).
- Tanzil marks: Tanzil stores shadda *before* the short vowel and gives the basmala of surahs 95 and 97 a
  shadda on the bāʾ. These are preserved exactly; tests assert byte equality with the XML for all 6,236 ayahs.
- **Before release:** download the current `quran-uthmani.xml` from https://tanzil.net/download/, replace the
  file, update `sha256`/`version` in the manifest, run `npm run content:build && npm test`.

## Structural metadata

Juz, hizb, rub‘ al-hizb, page (Madani 604), ruku, sajdah and Makki/Madani classification come from
`quran-meta@7` (Tanzil-derived). The build cross-checks every ayah id against the Tanzil text order.

A widely mirrored “Pickthall” JSON was rejected because it had been edited (e.g. “no God” → “no deity”, trailing
punctuation removed).

### Adding a translation
1. Download the official file (Tanzil: `tanzil.net/trans/<id>`, “Text (with aya numbers)”).
2. Save as `content-sources/translations/<id>.txt`, add a manifest entry with sha256, licence, translator.
3. `npm run content:build` (aborts unless all 6,236 rows align) → `npm test`.
Kannada (e.g. QuranEnc Hamza Batoor), Malayalam (Tanzil ml.abdulhameed / ml.karakunnu) and Tamil (Tanzil
ta.tamil / QuranEnc Baqavi) are the next candidates; each needs its licence confirmed.

## Not bundled (by design, until licensed)

Hadith, dua & adhkar collections, recitation audio, Adhan recordings, Moulid texts, learning material. Screens
for these are not shown rather than shown with placeholder content.
